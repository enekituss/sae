Consultando si el servicio municipal está publicando posiciones…

SAE Spotter consulta primero el recurso municipal resourceVehicles por línea para identificar los coches publicados y usar sus coordenadas cuando estén disponibles. Si esa consulta falla, utiliza las estimaciones por parada como respaldo; cuando no se publica GPS, la posición se reconstruye de forma aproximada sobre el trazado GTFS y se identifica como estimación.
